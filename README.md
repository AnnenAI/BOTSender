!help команада для просмотра всех команд и что они делают
!game команда начинает игру,  игра заканчивается автоматически когда в игре останутся нужное количество игроков,
указанное в описании при начале игры, для экстренного завершения игры необходимо выполнить команду !game с параметром  end (!game end)
